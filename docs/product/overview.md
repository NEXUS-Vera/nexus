# Product overview

Nexus is intended to become an agentic engineering platform in which Vera orchestrates specialist domain agents, shared memory and retrieval, project-board state, deterministic tools, and evaluations.

The first supported product slice is implemented. Its requirements, inputs, and output boundary are owned by [Embedded project initialization v1](./embedded-project-initialization-v1.md); [Current status in the root README](../../README.md#current-status) records what the shipped stack covers, and [ADR-0003](../decisions/ADR-0003-desktop-application.md) records the shipping form factor. The wider platform - orchestration across multiple domain agents, shared memory and retrieval, project-board state - is still a stated intent rather than an implementation.

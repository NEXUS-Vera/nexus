# Product overview

Nexus is intended to become an agentic engineering platform in which Vera orchestrates specialist domain agents, shared memory and retrieval, project-board state, deterministic tools, and evaluations.

The Phase 11 Project Board control plane provides artifact workspaces, governed revision commands, fake execution evidence, an append-only project ledger, graph traversal, and a board projection. Frontend project-board UI is not required for the kernel to operate.

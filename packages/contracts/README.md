# Nexus Contracts

## Purpose

Canonical shared schemas and interfaces for cross-agent and cross-module communication.

## Ownership boundary

Public contracts used by Vera, domain agents, apps, and tools for interoperability.

## What belongs here

- Versioned JSON schemas
- Shared interface definitions
- Compatibility examples and contract tests

## What must not be placed here

- Concrete agent implementations
- Application UI code
- Provider-specific SDK wiring
- Domain-only private schemas that never cross agent boundaries

## Current status

Placeholder only. Minimal v1 schema stubs and examples exist; no runtime clients yet.
